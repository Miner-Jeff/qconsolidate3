changelog=0.3.0 and 0.4.0 written by Claude (Anthropic AI, via Claude.ai) at the request of Miner-Jeff (GitHub), for QGIS 3.44 LTR.
    0.4.0
    - New default mode "Keep original formats": copies files as-is (with side-car files), once per file even when several layers share it
    - Layers without a file (scratch, PostGIS, WFS...) are exported to GeoPackage in that mode
    - Safeguard: a large file (over 100 MB) holding layers the project does not use is not copied whole; only the used layers are exported
    - Layers with unsaved edits are exported (with the edits) instead of copied
    - Same-named files from different folders no longer collide
    - All paths written through QGIS's own relative-path handling
    0.3.0
    - Fix About dialog crash on Python 3.12 (SafeConfigParser removed)
    - Never edit source layers (old version deleted 'fid' fields from the ORIGINAL data when exporting to GeoPackage)
    - Read layers only on the main thread; background task writes from thread-safe feature sources
    - Rasters: copy all side-car files (.tfw, .prj, .aux.xml, .ovr, ...), handle GeoPackage/NetCDF-style URIs
    - Unsupported, invalid or web layers are left pointing at their source with a warning instead of aborting
    - Joined and virtual (expression) fields are not baked into exported data
    - Correct relative paths (clears custom project home path, updates layer tree sources)
    - .qgz: auxiliary storage (.qgd) renamed along with the project
    - Asks to save unsaved projects first (previously crashed on layers added since the last save)
    - Qt6 / QGIS 4 compatible enums, no compiled PyQt5 resource file
